### 1. What is it?
Detects when an **object is nearby or blocking the IR sensor**.

### 2. Preferred component
**3-pin IR obstacle/proximity sensor**

### 3. Game Jam uses
- Detect hand movement
- Create an invisible button
- Detect when a player enters a zone
- Trigger an action without touching anything

### 4. Wiring

| IR Sensor | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| OUT | GPIO 27 |
