### 1. What are they? 
Detect **when a button or switch is pressed**. 
### 2. Preferred components
- **Momentary pushbutton** 
- **Microswitch / limit switch** 
### 3. Game Jam uses 
- Fire button → *Tilt Tank Tussle* 
- Nitro/brake → *Turbo Wheel* 
- Game controls → *Simon Says* 
- Detect when a physical mechanism reaches a position 

### 4. Wiring 
Use the ESP32's built-in pull-up resistor: 

**Button / switch → GPIO 27 → GND**
