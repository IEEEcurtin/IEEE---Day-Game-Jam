# Flappy Drone

Fly a drone through the gaps between pillars. Each gap passed scores a point, and the drone speeds up a little with each one until it reaches top speed at 25 points.

## Keys

| Key | Action |
|---|---|
| Space | Flap, also restarts |

Clicking or tapping also flaps.

## Controller

No dedicated controller. Any controller that sends Space works.

## Running it

Open `index.html` in Chrome or Edge.
