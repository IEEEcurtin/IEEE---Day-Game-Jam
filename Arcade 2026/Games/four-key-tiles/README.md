# Four Key Tiles

Tiles fall in four lanes. Hit the key under the lowest dark tile. A wrong key or a missed tile ends the run, and it speeds up as you go.

## Keys

| Key | Action |
|---|---|
| Q, W, O, P | Lanes 1 to 4 (F, G, H, J also work) |
| Space | Restart after game over |

Clicking or tapping a lane also works.

## Controller

Any controller that sends Q, W, O, and P (or F, G, H, and J) works.

## Running it

Open `index.html` in Chrome or Edge.
